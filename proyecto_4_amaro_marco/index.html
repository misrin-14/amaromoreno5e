Preguntas frecuentes

En esta seccion se presentaran algunas de las preguntas mas frecuentes sobre nuestro curso

¿Que es CSS?

Es un lenguaje de diseño gráfico que se utiliza para definir la apariencia visual de los documentos escritos en HTML o XML

¿Que es CSS Grid

Es un sistema de maquetación web en dos dimensiones (filas y columnas) que permite crear diseños de página complejos y adaptables de forma limpia y sencilla.

¿Que aprendere en este curso?

En este curso de CSS, aprenderas a diseñar, dar color, organizar y animar la parte visual de las páginas web.

¿Estas listo para aprender CSS?

Pasa de sitios web aburridos a experiencias visuales increíbles. Todo lo que necesitas saber sobre CSS esta en este curso
